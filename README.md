# Network-Labs-Packet-Tracer
Hands-on Packet Tracer labs documenting networking fundamentals, troubleshooting, and verification commands.

## Certifications
- CompTIA Network+
- CompTIA Security+

## What you’ll find in each lab
- .pkt project file
- Topology screenshot
- Device configs (routers/switches)
- Verification output (show commands + ping tests)
- Short README (goal, steps, results, lessons learned)

## Labs
- Lab 01 – VLANs + Trunking (in progress)
- Lab 02 – Inter-VLAN Routing (Router-on-a-Stick)
- Lab 03 – DHCP + DNS
- Lab 04 – ACL Basics
- Lab 05 – NAT/PAT

## Tools
- Cisco Packet Tracer
